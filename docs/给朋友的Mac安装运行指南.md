# 给朋友的 Mac 安装运行指南（保姆级）

> 这份文档是给**用 Mac 的朋友**看的。你（Windows 这边）只需要把压缩包发给他，
> 再让他按第三节一步步做即可。
>
> **Mac 版现在是真正的应用程序图标：双击 `Bordd` 就打开，和 Windows 上双击
> `Bordd_gui.exe` 完全一样。**

---

## 〇、先理解一件事（你必读，朋友可跳过）

**为什么不能直接把 Windows 的 exe 发过去？**

`Bordd_gui.exe` 是 Windows 程序，**Mac 完全无法运行**。
而打包工具 PyInstaller **不支持交叉编译**——macOS 版只能在 Mac 上生成。

所以方案是：给朋友一个 **`Bordd.app`**（Mac 的应用程序包）。
它里面有完整的程序本体，首次双击时会在 Mac 上自动安装所需组件
（约 1~3 分钟），**之后就是纯双击、秒开，不会再出现终端窗口**。

---

## 一、要传输什么（清单 + 每个文件的作用）

### 传输这一个文件即可

```
Bordd_mac.zip        约 130 KB
```

位置：`D:\PyCharm\work\add_border\mac_share\Bordd_mac.zip`

> 改过代码后重新生成（在 `bordd_dist` 目录下执行）：
> ```
> python make_mac_share.py
> ```

### 千万不要传的东西

| 文件 | 为什么不能传 |
| --- | --- |
| `bordd_dist\dist\Bordd_gui.exe` | Windows 专用，Mac 打不开 |
| `bordd_dist\dist\Bordd.exe` | 同上 |
| 整个工程文件夹 | 里面 40 MB 的 Windows 产物白占流量，`build/`、`.idea/` 等也都是垃圾 |

### 压缩包解开后是什么

```
Bordd_mac/
├── Bordd                ← ★ 这就是应用程序，双击它（其余都不用管）
├── 使用说明.txt          给朋友看的简明说明
└── 界面预览.png          界面长什么样（让他知道成功的样子）
```

`Bordd` 那个图标其实就是 `Bordd.app`——macOS 默认隐藏 `.app` 后缀，
所以看起来就叫「Bordd」。

### 展开看，`Bordd.app` 里是什么

按住 Control 点它 →「显示包内容」，可以看到：

```
Bordd.app/
└── Contents/
    ├── Info.plist                 应用的"身份证"：名字、图标、版本、可执行入口
    ├── PkgInfo                    固定标记（APPL????）
    ├── MacOS/
    │   └── Bordd                  ★ 双击 .app 时由 macOS 执行这个脚本
    │                                它判断"环境好了就直接开界面，没好就先装"
    └── Resources/
        ├── lib.sh                 共用函数（找 Python、弹窗、路径）
        ├── setup.sh               首次运行：建环境 + 装组件 + 开界面
        ├── Bordd.icns             应用图标（Dock / 访达里显示的那个）
        └── app/                   程序本体
            ├── bordd.py           核心：加边框、压缩、导出 PDF
            ├── bordd_gui.py       图形界面：窗口、按钮、预览
            └── assets/            图标资源
```

| 文件 | 一句话作用 |
| --- | --- |
| `Contents/MacOS/Bordd` | **双击的总入口**。环境就绪 → 直接开界面；首次 → 弹窗提示后开终端装依赖 |
| `Contents/Resources/setup.sh` | 首次安装：找 Python、建独立环境、装 Pillow / pikepdf、开界面 |
| `Contents/Resources/lib.sh` | 上面两个脚本共用的工具函数 |
| `Contents/Info.plist` | 告诉 macOS 这叫什么名字、用什么图标、双击时运行谁 |
| `Contents/Resources/Bordd.icns` | 应用图标 |
| `Contents/Resources/app/bordd_gui.py` | 图形界面代码 |
| `Contents/Resources/app/bordd.py` | 核心功能代码 |
| `使用说明.txt` | 朋友忘了怎么操作时可以再看一遍 |

**朋友只需要认识 `Bordd` 一个图标。**

运行成功后，Mac 上会多出两个文件夹（**不用管、别删**）：

```
~/Library/Application Support/Bordd/     运行环境（Python 组件装在这里）
~/Library/Logs/Bordd/                    日志
```

## 二、怎么把文件发过去

任选一种（推荐前两种）：

| 方式 | 注意事项 |
| --- | --- |
| **微信 / QQ 传文件** | 直接发 `Bordd_mac.zip`。让朋友在 **Mac 版微信/QQ** 里点「下载」，不要只点「预览」 |
| **邮件附件** | 130 KB，任何邮箱都能发 |
| **网盘** | 上传 zip，朋友下载 |
| **U 盘** | 需要 exFAT 格式 |

⚠️ **重要：一定要发 `.zip`，不要让朋友自己重新压缩一遍。**

本项目这个 zip 是用脚本专门打的，里面记录了文件的「可执行权限」——
macOS 双击 `.app` 必须靠这个权限。用普通压缩工具重打会丢失它，
表现就是双击没反应。第四节 Q2 有补救办法，不用重传。

## 三、朋友的操作步骤（可以直接把这一节转给他）

### 第 1 步：装 Python（只需一次）

> 如果他的 Mac 已经装过 Python 3.10 或更新版本，这步跳过。

1. 打开浏览器，访问：

   ```
   https://www.python.org/downloads/macos/
   ```

2. 找到**黄色的大按钮** `Download Python 3.13.x`（版本号可能不同），
   下面小字标着 `macOS 64-bit universal2 installer`。**点它下载。**

3. 下载完成后，在「下载」文件夹里**双击**那个 `.pkg` 文件。

4. 依次点：「继续」→「继续」→「同意」→「安装」
   （中途可能要求输入**开机密码**）→ 等进度条走完 →「关闭」。

✅ **完成标志**：`应用程序` 里出现一个叫 `Python 3.13` 的文件夹。

---

### 第 2 步：双击 Bordd

1. 双击 `Bordd_mac.zip` 解压（用 macOS 自带的解压，不要用别的解压软件）。

2. 进入 `Bordd_mac` 文件夹，找到 **`Bordd`** 图标，**双击**。

3. **第一次打开会被 macOS 拦下来**：

   > 「Bordd」无法打开，因为 Apple 无法检查其是否包含恶意软件。

   这是 macOS 对网上下载文件的正常保护，不是病毒。这样处理：

   - 点「完成」**把提示关掉**
   - **右键**（或按住 Control 点）`Bordd` 图标
   - 在菜单里选「**打开**」
   - 再问一次时，点「**打开**」

   ✅ 只有第一次需要这样，以后直接双击就行。

4. Bordd 会弹一个小窗口，告诉你第一次运行要联网装组件。点「**好**」。

5. 接着会**自动打开一个黑色终端窗口**，滚动显示安装进度。
   第一次大约 **1~3 分钟**，请耐心等，**不要关窗口**。

6. 装完后图形界面会自动弹出来 🎉

   > 界面如果没跳到最前面，点一下 Dock 里的 **Bordd** 图标即可。

---

### 第 3 步：以后就这么用

**直接双击 `Bordd` 图标，秒开，不会再出现终端窗口。**

想更方便的话，把 `Bordd` 拖进「应用程序」文件夹，
就能像普通软件一样从「启动台」里打开。

> 界面说明：
> 1. 「输入目录」→ 点「浏览…」，选放图片的文件夹
> 2. 「输出目录」会自动填好，一般不用改
> 3. 「目标比例」选 4:3（或其它比例，也可以手输 `21:9`）
> 4. 「边框颜色」选黑色或白色
> 5. 点蓝色按钮「开始处理」

## 四、常见问题（朋友遇到问题先查这里）

### Q1：双击 Bordd 提示「无法打开」「来自身份不明的开发者」

正常保护机制。**先点「完成」关掉提示**，然后**右键**点 `Bordd` 图标 →
「**打开**」→ 再点「**打开**」。只有第一次需要。

### Q2：双击 Bordd 完全没反应

说明 zip 传输过程中「可执行权限」丢了。用终端补救（**一分钟**）：

1. 按 `Command + 空格`，输入 `终端`，回车
2. 在终端里输入这一行（`chmod` 后面有一个空格）：

   ```
   chmod -R +x 
   ```

3. **先不要回车。** 把 `Bordd` 图标从访达窗口**直接拖进终端窗口**
   （终端里会自动补上一长串路径）
4. 按回车

之后再双击 Bordd 就正常了。

### Q3：弹窗说「没有找到 Python」

第 1 步没做或没成功。按第 1 步装一遍 Python，然后重新双击 Bordd。

> 注意：macOS 自带的 `python3` 可能是 Xcode 附带的旧版本，不能算数。

### Q4：终端里提示「Pillow 安装失败」

九成是网络问题。检查 Wi-Fi 或换**手机热点**，然后重新双击 Bordd
（已装好的部分不会重复下载）。

### Q5：安装很慢 / 卡住不动

国内访问国外软件源本来就慢，**耐心等**。
超过 10 分钟没有任何新文字，按 `Control + C` 中断，换热点后重来。

### Q6：我想输出 PDF，提示不支持

PDF 模式需要额外组件 `pikepdf`，它**在 macOS 13 及更早的系统上可能装不上**
（官方新版只提供 macOS 14+ 的安装包）。

**不影响其它功能**，用「保持原格式」或「统一无损 PNG」即可。

### Q7：程序窗口关掉后，黑窗口还在

直接关掉黑窗口即可。正常情况只有第一次会弹。

### Q8：会不会弄乱我的电脑？怎么卸载？

**不会。** 组件都装在下面这个文件夹，不碰系统自带的 Python：

```
~/Library/Application Support/Bordd
```

卸载：把 `Bordd` 拖进废纸篓，再删掉上面那个 `Bordd` 文件夹即可。

### Q9：界面出来了但报错

错误日志在 `~/Library/Logs/Bordd/error.log`，发给对方排查即可。

## 五、可选：做成完全独立的 App

现在这个 `Bordd` 是「启动器 + 本机运行环境」的形式：
**安装包只有 130 KB**，但目标电脑需要装一次 Python。

如果需要一个**把 Python 也打包进去、可以随手拷给任何 Mac 用**的
完全独立 App，需要在一台 Mac 上用源码重新打包：

```bash
cd <完整源码目录>/bordd_dist
python3 -m pip install pyinstaller
bash build_mac.sh
```

成功后会得到 `bordd_dist/dist/Bordd.app`（约 50 MB），那个才是自包含的。

> ⚠️ 它是「目录模式」的 App，**必须整个 `Bordd.app` 一起拷**，
> 不能只拷里面的可执行文件，否则会缺少 `Contents/Frameworks/` 而无法启动。
> 好处是不依赖系统临时目录、启动也更快。

> 也可以在 GitHub 上建仓库后用自带的 Actions 自动构建
> （见仓库 `.github/workflows/build.yml`），从 Actions 页面下载
> `Bordd-macos` 产物。

## 六、给你的建议（Windows 这边）

1. **发之前先自己确认**：解压 `Bordd_mac.zip`，应该看到
   `Bordd`（图标）、`使用说明.txt`、`界面预览.png` 三样东西。

2. **把这份文档也发给他**（或只发第三节 + 第四节）。

3. **预期管理**：告诉他「第一次要装个 Python，之后就跟普通软件一样，
   双击图标就能用」，免得他看到黑窗口就慌。

4. 如果他卡住，让他**把终端窗口截图发给你**。

## 附：一次性成功的关键点

| 关键点 | 说明 |
| --- | --- |
| ✅ 发 `Bordd_mac.zip`，不发 exe | exe 是 Windows 专用的 |
| ✅ 用本项目脚本打的 zip | 里面记录了 `.app` 内部文件的可执行权限 |
| ✅ 先装 python.org 的 Python | Mac 自带的 python3 版本可能太旧 |
| ✅ 首次打开用「右键 → 打开」 | 绕过 macOS 的下载文件保护 |
| ✅ 第一次运行要等 1~3 分钟 | 在联网装组件，属正常 |
| ✅ 只有第一次会弹终端 | 之后双击是纯图形启动，和 Windows 一致 |
| ✅ 界面没跳出来就点 Dock 的 Bordd 图标 | Tk 窗口偶尔不会自动置前 |
