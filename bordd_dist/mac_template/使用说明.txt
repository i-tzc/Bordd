================================================================
 Bordd —— Mac 使用说明
 图片批量加边框工具
================================================================

用法和 Windows 软件一样：双击图标就打开，不需要敲命令。


----------------------------------------------------------------
 只有三步
----------------------------------------------------------------

第 1 步：装 Python（只需一次，约 3 分钟）

   1. 打开浏览器，访问：https://www.python.org/downloads/macos/
   2. 点页面上那个最大的黄色按钮 "Download Python 3.x.x"
      （下载下来是一个 .pkg 文件）
   3. 双击那个 .pkg 文件，一路点「继续」→「同意」→「安装」
      （中途可能要求输入开机密码，输入即可）
   4. 装完点「关闭」

   ※ 如果电脑上已经装过 Python 3.10 或更新的版本，这步可以跳过。


第 2 步：双击 Bordd 图标

   在 Bordd_mac 文件夹里，找到这个图标：

        Bordd        （左边有个小图标的那个，就是应用程序）

   双击它。

   ▸ 第一次打开可能被 macOS 拦下来，提示
     「无法打开，因为 Apple 无法检查其是否包含恶意软件」：

        先点「完成」关掉提示，
        然后【右键】点 Bordd 图标 → 选「打开」→ 再点「打开」。

        （只有第一次需要这样，以后直接双击就行）

   ▸ 接着 Bordd 会弹一个窗口，告诉你第一次运行要联网装组件。
     点「好」。

   ▸ 然后会自动打开一个黑色终端窗口，滚动显示安装进度。
     第一次大约需要 1~3 分钟，请耐心等，不要关窗口。

   ▸ 装完后图形界面会自动弹出来，就成功了！

   ※ 界面没跳到最前面的话，点一下 Dock 里的 Bordd 图标即可。


第 3 步：以后就这么用

   直接双击 Bordd 图标即可，秒开，不会再出现终端窗口。

   想更方便的话，把 Bordd 图标拖进「应用程序」文件夹，
   就能像普通软件一样从「启动台」里打开。


----------------------------------------------------------------
 怎么用（界面说明）
----------------------------------------------------------------

   1. 「输入目录」→ 点右边「浏览…」，选放图片的文件夹
   2. 「输出目录」会自动填好，一般不用改
   3. 「目标比例」选 4:3（或你想要的其它比例）
   4. 「边框颜色」选黑色或白色
   5. 点「开始处理」

   处理好的图片就在输出目录里。


----------------------------------------------------------------
 常见问题
----------------------------------------------------------------

Q：双击 Bordd 提示「无法打开」「来自身份不明的开发者」
A：这是 macOS 对从网上下载的文件的正常保护，不是病毒。
   先点「完成」关掉提示，然后【右键】点 Bordd 图标 →「打开」
   → 再点「打开」。只有第一次需要。

Q：弹窗说「没有找到 Python」
A：说明第 1 步还没做或没装成功。按第 1 步装一遍 Python，
   然后重新双击 Bordd。

Q：终端里提示「Pillow 安装失败」
A：多数是网络问题。检查 Wi-Fi，或者换成手机热点，
   然后重新双击 Bordd（装好的部分不会重复下载）。

Q：安装很慢 / 卡住不动
A：国内访问国外软件源本来就慢，耐心等。
   如果超过 10 分钟没有新文字，按 Control + C 中断，换热点重来。

Q：我想输出 PDF，提示不支持
A：PDF 模式需要一个额外组件（pikepdf），它在部分较旧的 macOS 上
   装不上。不影响其它功能，用「保持原格式」或「统一无损 PNG」即可。

Q：每次打开都弹出终端窗口
A：正常情况只有第一次会。如果每次都弹，说明环境没装成功，
   请看终端里的报错，或把截图发给对方。

Q：界面出来了但里面是空的 / 报错
A：错误日志在 ~/Library/Logs/Bordd/error.log，可以发给对方排查。

Q：会不会弄乱我的电脑？怎么卸载？
A：不会。组件都装在下面这个文件夹里，不碰系统自带的 Python：
       ~/Library/Application Support/Bordd
   卸载方法：把 Bordd 图标拖进废纸篓，再删掉上面那个 Bordd 文件夹即可。


----------------------------------------------------------------
 这些文件都是干什么的
----------------------------------------------------------------

  Bordd               ← 就是应用程序，双击它（其余都不用管）
  使用说明.txt        ← 本文件
  界面预览.png        ← 界面长什么样

  运行后会自动产生（不用管、别删）：
  ~/Library/Application Support/Bordd/    运行环境
  ~/Library/Logs/Bordd/                   日志

  Bordd 图标上【右键】→「显示包内容」，可以看到程序本体：
  Contents/Resources/app/ 里面是 bordd.py 和 bordd_gui.py。


----------------------------------------------------------------
 关于「独立 App」
----------------------------------------------------------------

这个 Bordd 是「启动器 + 本机运行环境」的形式：
安装包很小（约 130 KB），但需要目标电脑装一次 Python。

如果你需要一个把 Python 也打包进去、可以随手拷给别人的
完全独立 App，需要在一台 Mac 上用源码重新打包：

    cd <完整源码目录>/bordd_dist
    python3 -m pip install pyinstaller
    bash build_mac.sh

成功后会在 bordd_dist/dist/ 下得到 Bordd.app，
那个才是完全自包含的版本。
